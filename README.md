\# Flight Delay Data Analysis Using Hadoop MapReduce and Apache Pig



\## Project Overview



This project analyzes the 2024 U.S. Flight Delay Dataset using Hadoop MapReduce and Apache Pig for the Big Data Analysis Lab.



The dataset contains more than 7 million flight records and was processed using Hadoop Distributed File System (HDFS).



\## Dataset Information



\- Dataset: Flight Data 2024

\- Total Records: 7,079,081

\- Columns: 35

\- Original Dataset Size: Approximately 1.3 GB

\- Format: CSV

\- Source: Kaggle / BTS Flight Data



> The original 1.3 GB dataset is not included in this repository because of its large file size.



\## Technologies Used



\- Apache Hadoop 3.2.4

\- Hadoop HDFS

\- Hadoop MapReduce

\- Apache Pig 0.18.0

\- Java 8

\- Windows CMD

\- Git \& GitHub



\## MapReduce Analysis



1\. Total Flights by Airline

2\. Average Departure Delay by Airline

3\. Average Arrival Delay by Origin Airport

4\. Total Flights by Origin Airport

5\. Cancelled Flights by Airline



\## Apache Pig Analysis



1\. Total Flights by Airline

2\. Total Flights by Month



\## Key Results



\- Total flight records analyzed: 7,079,081

\- Southwest Airlines (WN) had the highest number of flights: 1,419,419

\- American Airlines (AA) had the highest average departure delay among the analyzed airlines: approximately 20.70 minutes

\- American Airlines (AA) had 15,252 cancelled flights
